# Landing Page para Clínica Odontológica

Projeto desenvolvido com HTML, CSS e JavaScript, focado na criação de uma landing page moderna, responsiva e intuitiva para clínicas odontológicas.

A aplicação apresenta informações essenciais sobre a clínica e seus profissionais, incluindo apresentação do dentista, especialidades, serviços oferecidos, formas de contato e agendamento. O design foi pensado para transmitir confiança, profissionalismo e proporcionar uma excelente experiência ao usuário em diferentes dispositivos.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Design moderno e responsivo
* Seção de apresentação da clínica e do dentista
* Exibição de especialidades e serviços odontológicos
* Informações de contato e localização
* Interface intuitiva e atrativa
* Navegação fluida e otimizada

## Objetivo

Desenvolver uma página institucional capaz de fortalecer a presença digital de clínicas odontológicas, destacando seus serviços e facilitando o contato com potenciais pacientes.
